Issue #1846 — When the API returns a non-JSON error, users get an uninformative ClassCastException. Open 18+ months. Business Risk: erodes merchant trust and support load as Stripe scales global reliability.

PR #2149 — Malformed webhook timestamps cause unhandled exceptions. Developer Impact: webhook reliability is the backbone of agent-ready commerce and event-driven architectures.
